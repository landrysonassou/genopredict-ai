GenoPredict-AI : est une plateforme d'apprentissage automatique (Machine Learning) dédiée à l'analyse génomique, à la prédiction de traits complexes et au diagnostic moléculaire.

Le projet vise à intégrer des données biologiques et génétiques (polymorphismes, marqueurs moléculaires, expressions géniques) pour développer des modèles prédictifs haute performance applicables à la santé humaine et aux sciences biologiques.

 Objectifs principaux

Traitement & Analyse de Données : Nettoyage, structuration et exploration de données génomiques et bio-statistiques.
Modélisation Prédictive : Entraînement d'algorithmes de Machine Learning pour la prédiction de phénotypes et la classification de biomarqueurs.
Analyse de Biomarqueurs : Évaluation de l'impact de polymorphismes génétiques et de facteurs biologiques sur des traits cibles.
Outil Interactif : Déploiement d'une interface utilisateur (web) permettant l'exploration visuelle et le test des modèles en temps réel.

Technologies utilisées

Langage principal : Python
Science des données & ML : Pandas, NumPy, Scikit-learn, SciPyVisualisation : Matplotlib, Seaborn
Déploiement / Interface : Streamlit
